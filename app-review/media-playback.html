Wayne Kastro: media playback

Google Play-installed Android version 1.0 (build 2). The user taps Play on “Trapped Inside” in Members, then returns to the Android home screen while playback continues.

0–10 seconds: Members playback screen. 10–25 seconds: user starts playback and the player shows Pause and playback progress. 25–45 seconds: app moves to the background.

This user-initiated audio uses FOREGROUND_SERVICE_MEDIA_PLAYBACK. Delaying or interrupting the task interrupts the music the user chose to hear. Playback stops when the user pauses it.
