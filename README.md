# Wayne Kastro

Official artist website: https://waynekastro.com

Edit content securely at https://console.richrowmusic.com/addons/admin?site=waynekastro

Keep the page address `waynekastro`. Add headings Music, Videos, Photos, About, Booking and Connect, then add content blocks beneath each heading. Upload public media through Media Library. Select Publish this page and Save Page. Only published pages and public media are returned. Admin credentials stay in the private console.

GitHub Pages publishes the main branch root. This repository contains the public design and the domain CNAME; it has no credentials or private media.
